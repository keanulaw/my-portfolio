# Shannon Keanu A. Yase — Portfolio

Developer portfolio built with React 19, Vite, and Tailwind CSS. The redesign uses locally hosted Inter, warm neutral colors, a muted green accent, editorial project layouts, and small CSS transitions. No new runtime dependencies were added.

## Content

All six original projects, existing external links, education, certifications, skills, and profile artwork are preserved. The AI edit pipeline leads the work section, with an expandable case study and an explanatory workflow diagram. Experience is based on the existing project description; no employers, employment dates, or metrics have been invented.

## Development

- `npm ci` — install locked dependencies
- `npm run dev` — start Vite
- `npm run build` — create production output in `dist`
- `npm run preview` — preview production output
- `npm run lint` — run the repository's ESLint configuration

Deploy as a static Vite site with build command `npm run build` and output directory `dist`. Existing Vercel compatibility is preserved.

## Accessibility and performance

Semantic sections, visible keyboard focus, a skip link, native case-study disclosure, mobile navigation with Escape handling, active section links, and reduced-motion support. Images have reserved dimensions and lazy loading. The Inter variable font is self-hosted; its license is in `public/fonts/LICENSE.txt`.
